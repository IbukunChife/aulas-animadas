## Como adicionar uma trilha

Cada trilha é uma pasta na raiz com o próprio `index.html` (o portal da trilha) e uma subpasta por deck. Depois de criar a pasta, adicione um card no `index.html` da raiz e uma linha na tabela de trilhas acima.
